# V2.3.5 新增接口用法

以下片段沿用 `github.com/fishpioffical/golang-sdk/sdk` 和 `types` 包。普通 API 使用原有 `sdk.NewSDKWithAPIKey`；OAuth 可以用不带 API Key 的实例。

## OAuth

```go
client := sdk.NewSDKWithAPIKey("")
loginURL := client.GetOpenIdUrlWithScopes(
    "https://example.com",
    "https://example.com/callback",
    "profile.read", "points.read",
)
// 让用户浏览器访问 loginURL；将本次登录与服务端会话绑定。
_ = loginURL
```

在服务端回调中，先校验回调属于自己发起的登录会话，以及 return_to / nonce 与预期相符，再传递收到的 OpenID 参数：

```go
params := make(map[string]string)
for key, values := range r.URL.Query() {
    if len(values) == 1 {
        params[key] = values[0]
    }
}
verified, err := client.PostOpenIdVerifyWithTokens(params)
if err != nil {
    return err
}
// verified.OpenID 为已校验的用户 ID。
// 将 verified.OAuthTokens 安全保存在服务端，不要记录到日志。
profile, err := client.GetOAuthProfile(verified.AccessToken)
if err != nil {
    return err
}
if profile.Code != 0 {
    return fmt.Errorf("用户资料请求失败: %s", profile.Msg)
}
if profile.Data == nil {
    return errors.New("用户资料为空")
}
fmt.Println(profile.Data.UserName)
```

令牌过期时主动调用续签，成功后原子替换保存的新旧令牌：

```go
renewed, err := client.PostOpenIdToken(savedRefreshToken)
if err != nil {
    return err
}
if renewed.Code != 0 || renewed.Data == nil {
    return errors.New("续签失败，需要重新授权")
}
// 安全保存 renewed.Data，尤其是新的 RefreshToken。
// 同一账号的续签操作应串行化；旧令牌复用可能导致整个令牌族失效。
```

SDK 不自动保存或重试续签。OAuth 方法不继承 `WithLogDir` / `WithCustomUnmarshaler`，避免请求/响应令牌进入日志。普通 API 的选项行为保持原样。

分页接口 `GetOAuthPoints(token, page, size)`、`GetOAuthArticles(token, page, size)` 使用 0 表示服务端默认值。积分每页最大 200，发帖每页最大 100。详细资料、VIP 信息分别调用 `GetOAuthUserDetail`、`GetOAuthMembership`，需要对应的授权 scope。

## 草稿

```go
client := sdk.NewSDKWithAPIKey(apiKey)
articleType, zero, commentable := 6, 0, false
saved, err := client.PostArticleDraft(&types.PostArticleDraftRequest{
    ArticleTitle: "第一章",
    ArticleContent: "正文",
    ArticleType: &articleType,
    ColumnID: columnID,
    ChapterNo: "1",
    ArticleCommentable: &commentable,
    ArticleRewardPoint: &zero,
})
if err != nil {
    return err
}
if saved.Code != 0 || saved.Data == nil || saved.Data.Draft == nil {
    return errors.New("保存草稿失败")
}
draftID := saved.Data.Draft.OId
_ = draftID
```

- `ArticleDraftID` 留空新建，填写则更新。
- 保存请求发送完整的字符串字段，空字符串可以清空内容；更新前先读详情，避免用不完整的数据覆盖原内容。
- 可选布尔和数字使用指针：`nil` 不发送；`&falseValue` / `&zero` 显式发送 `false` / `0`。
- `GetArticleDrafts()` 返回列表，`GetArticleDraft(id)` 返回包含正文的详情，`DeleteArticleDraft(id)` 删除指定草稿。
- 列表和保存响应不含正文，不能直接当作完整草稿再次保存。

## 复读机与专栏封面

| 方法 | 用途 |
| --- | --- |
| `GetRepeaterItems("joke")` | 查询段子；空类型查询全部 |
| `GetRepeaterNext("fish", previousID)` | 随机一条，尽量排除上一条 |
| `PostRepeater("kfc", content)` | 上传内容，服务端验证 2–500 字符 |
| `PostRepeaterLike(id)` | 切换点赞状态，检查响应 `Data.Liked` |
| `PostColumnCover(columnID, imageURL)` | 设置专栏封面 |
| `PostColumnCover(columnID, "")` | 清空专栏封面 |

这些方法均返回类型化 `ApiResponse`。调用时先检查 `error`，再检查 `Code`，最后检查需要使用的 `Data` / `Item` / `Column` 是否为 nil。随机接口没有内容时 `Item` 可能为 nil。
